# QuakeAlert trademark policy

This is a trademark policy. It is separate from copyright licensing:
the GPLv3/AGPLv3 licenses grant copyright (and patent) permissions only
and grant no trademark rights. Nothing in `firmware/LICENSE`,
`server/LICENSE`, or `LICENSING.md` permits use of the marks below.

## 1. The marks

- The word mark **"QuakeAlert"**
- The QuakeAlert logo (`docs/brand/quakealerticon.svg`,
  `docs/brand/quakealerticontr.svg`)
- The designation **"Official QuakeAlert Node"**

## 2. What always needs written permission

- Using the marks on hardware or in software branding, packaging,
  advertising, or app-store listings, except as §3 allows.
- Calling any device, build, firmware, server, or app an
  "Official QuakeAlert Node" (or otherwise presenting it as official)
  unless it is an unmodified official release distributed by the project
  or produced under an explicit written authorization.
- Using the logo, in whole or in recognizable part, for any purpose
  without written permission.

## 3. Nominative fair use (no permission needed)

You may use the word "QuakeAlert" in plain text to truthfully describe
compatibility or origin, for example: "compatible with QuakeAlert MQTT
trigger payloads" or "a community fork of the QuakeAlert firmware". Such
use must not suggest endorsement, affiliation, or official status, must
not use the logo, and must not be more prominent than necessary.

## 4. Forks and modified versions

- Forks must rename their distributions (software and hardware) so the
  QuakeAlert name does not appear in product names, device labels, boot
  screens, or app titles.
- Forks must remove the QuakeAlert logo from all user-visible surfaces.
- Forks must not use "Official QuakeAlert Node" for any modified build.
- A factual statement of origin (e.g. "forked from QuakeAlert, GPLv3")
  in documentation or source is permitted and does not require
  permission, provided it follows §3.

## 5. Modified or unofficial hardware and software

- Modified firmware, third-party sensor boards, unofficial servers, and
  unofficial apps must avoid implying official endorsement: no QuakeAlert
  name or logo on enclosures, PCBs, packaging, listings, or primary UI.
- Where the software license requires marking modifications (GPLv3 §5 /
  AGPLv3 §5), those modification notices must additionally make clear the
  build is unofficial.
- Unofficial nodes must not present themselves to the official network
  as official nodes.

## 6. Permission requests

Contact the project maintainers in writing, describing the exact use
(product, markings, distribution channel, duration). Permission, if
granted, is non-exclusive, non-transferable, revocable for misuse, and
limited to the approved use.
